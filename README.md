# 🥘 Teeyai

### 📱 Final Project for Mobile Application Development 

This project is a **final group project (3 members)** developed using **Flutter** with **Dart** and **Firebase** as the backend database.  
It’s a complete mobile solution for **ordering food in a Shabu restaurant**, designed for both customers and restaurant staff.

---

## 🚀 Features

- 🧍‍♂️ **Customer Side**
  - Browse menu and select food items  
  - Order directly through the mobile app  
  - Confirm orders per table  
  - View total cost in real-time

- 🧑‍💼 **Admin / Backend System**
  - Manage orders and confirm each table’s order  
  - Full **CRUD operations** (Create, Read, Update, Delete)  
  - Real-time database connection with Firebase  
  - Automatic billing system for each table
